📱 App 1 — Acelerômetro

Este aplicativo foi desenvolvido no MIT App Inventor com foco na utilização do sensor acelerômetro do dispositivo. O app utiliza diferentes imagens e elementos visuais para deixar a interface mais atrativa e interativa. Foram utilizados comandos e blocos específicos do MIT App Inventor para identificar os movimentos e a inclinação do celular, fazendo com que os elementos da tela respondam de acordo com a movimentação do aparelho. O projeto demonstra na prática como sensores podem ser utilizados para criar aplicativos interativos.

🎱 App 2 — Bilhar

Este aplicativo simula um jogo de bilhar, desenvolvido utilizando diferentes imagens para representar a mesa, bolas e outros elementos do jogo. Foram utilizados diversos blocos e comandos do MIT App Inventor, incluindo movimentação de objetos, colisões e controles para tornar a experiência mais próxima de um jogo real. O projeto também trabalha com elementos gráficos e lógica de programação para controlar o comportamento das bolas durante a partida.

🧱 App 3 — Brick Breaker

Este aplicativo é baseado no clássico jogo Brick Breaker, no qual o jogador deve controlar uma plataforma para rebater uma bola e destruir os blocos. O projeto foi desenvolvido no MIT App Inventor, utilizando imagens diferentes para criar a identidade visual do jogo e diversos comandos para controlar a movimentação da bola, da plataforma e dos blocos. Também foram utilizadas condições e eventos para detectar colisões, remover os blocos atingidos e controlar a pontuação, demonstrando o uso de diferentes recursos de programação disponíveis no MIT App Inventor.
